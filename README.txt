 Student Results Management System
Language:
Python 3
GUI Library:
Tkinter


Additional Library:
NumPy
Data Storage:
JSON (students.json)
 
 Project Description: 
 The Student Results Management System is a Python-based desktop application developed using Tkinter. 
 It helps users manage student records easily through a graphical user interface (GUI). Student information is
 stored permanently in a JSON file, and NumPy is used to generate statistical analysis of student marks.

 Features:
1. Add Student
2. Search Student
3. Update Student
4. Delete Student
5. Show All Students
6. Clear Input Fields
7. Display Student Statistics
8. Save Data to JSON File
9. Load Data Automatically
10. Message Box Notifications

NumPy is used to calculate:
- Average Marks
- Highest Marks
- Lowest Marks
- Total Number of Students
